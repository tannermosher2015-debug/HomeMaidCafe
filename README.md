# Home Maid Cafe — concept site

A single-page concept/pitch website for **Home Maid Cafe**, a family-run breakfast spot in
Azeka Shopping Center, Kihei, Maui. Built by **Frontline Web Designs**.

**This is an unofficial concept** — not the official Home Maid Cafe site. It is `noindex`,
menu prices are placeholders pending the owner, and photos are sourced from the Google business
listing (contributor-credited); usage rights to be confirmed before any public launch.

## Stack
Single-file, hand-built **HTML/CSS/JS** — no frameworks, no build step. Open `index.html`.

## Design
Warm-organic direction (one word: *Home*). Fraunces × Hanken Grotesk; a restrained
bone / guava / malasada-gold / cocoa palette; a hand-drawn ring motif. Built to the
[$10K checklist](https://meticsmedia.com): committed point of view, working typography,
restrained color, breathing hierarchy, intentional imagery, motion that whispers,
mobile-that's-designed (sticky call bar), and the invisible stuff — WCAG AA contrast,
semantic HTML, keyboard/focus support, JSON-LD, preloaded hero, lazy media.
